# Smart Library Project

## Lab Session 06: Implementation – Part 1

### Objective
To implement a basic book checkout system using Java.

### Basic Theory
Clean code is easy to read and understand. GitHub is used to store source code and manage changes.

### Features
- Store book ISBN and title.
- Track book availability.
- Issue a book when it is available.
- Display a message when a book is already issued.

### Technology Used
- Java
- GitHub
- Programiz Online Java Compiler

### Source Code
The Book.java file contains the Book class and checkout functionality.
